# 男朋友拍照救星 · Boyfriend Savior from Bad Shots

> 让每一次举起手机，都不再是一场赌博。

---

## 这是什么

一个帮「男朋友」把照片拍好的工具。

它的核心假设很简单：**拍照的人不是不想拍好，而是不知道此刻该怎么拍。**
所以这个项目不教审美，只解决"手该往哪放"的问题——在按快门之前给出可执行的建议，在按快门之后把能救的照片救回来。

> ⚠️ 本 README 是项目立项阶段的项目构想，仓库当前尚无代码实现。功能与技术选型均为推荐方案，欢迎讨论与推翻。

---

## 痛点

| 场景 | 真实发生的事 |
| --- | --- |
| 逆光 | 背景美如画，人脸黑成一团 |
| 顶光 | 眼窝、鼻影、法令纹，一个都没放过 |
| 构图 | 人在正中间，头顶一片天，脚下被裁掉 |
| 连拍 | 拍了 87 张，挑不出一张不闭眼、不糊、不歪的 |
| 后期 | 想修但不会修，滤镜一上更假 |
| 情绪 | 表情从期待 → 耐心 → 失望 → "算了，我来拍吧" |

最后一条才是真正的成本。

## 核心功能（推荐）

1. **实时构图引导**
   取景框内叠加九宫格与引导线，根据被摄者的位置提示"往左一点""蹲下来""手机举过头顶"。

2. **光线预警**
   检测逆光、顶光、混色温环境，提示"让人转 90 度"或"开启 HDR"，而不是拍完才发现。

3. **连拍精选**
   从一组连拍里自动挑出：不闭眼、表情自然、不模糊、人像居中的那几张。这一条往往比实时引导更能救命。

4. **姿势与角度建议**
   按场景（街拍 / 海边 / 咖啡馆 / 夜景）给出 3~5 条具体到"手放哪、脚朝哪"的提示，而不是抽象的"自然一点"。

5. **一键后期**
   自动修脸型、提亮面部、统一色调、去除画面杂物。目标是"看得出是她，但状态更好"。

6. **拍摄前速查**
   出门前 30 秒能看完的清单，降低临场大脑空白。

## 技术选型（建议）

- **端侧优先**：相机与实时推理跑在设备上，照片默认不出设备。拍照场景对延迟极敏感，上云会直接毁掉体验。
- **推理能力**：轻量人脸检测 + 姿态估计 + 人像质量打分模型；后期部分走图像生成/修复链路。
- **拍摄接入**：Android CameraX / iOS AVFoundation。
- **隐私**：本地处理为默认，云端能力必须显式授权且可关闭。

## 快速开始

项目尚未开始编码，暂无安装与运行方式。

如果你希望它先以最小形态跑起来，推荐的第一步是最简单的那个：**一个只做连拍精选的命令行/小组件原型**——输入一组照片，输出排序后的最佳几张。它不依赖相机权限、不依赖实时性能，最容易验证"救星"这个价值主张是否成立。

## 命名由来

`boyfriend-savior-from-bad-shots`——从烂照片里拯救男朋友。

主语是"男朋友"，因为出问题的从来不是相机，是拍照的那个人；而"救星"是这个工具要扮演的角色。名字里带一点自嘲，但目标很认真。
